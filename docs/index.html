写作与表达002

ASD–STE100

v0.4.0 · 安装快照

asd-ste100

把容易误读的英文，改成清楚的技术表达。
适合提示词、工具描述和 Agent 之间的指令。

BEFORE

If the request fails, the worker should retry it; if the retry also fails, it must report the error.

AFTER ↘

If the request fails, the worker should retry it.
If the retry also fails, it must report the error.

减少歧义技术英语结构检查保留原意
