同一份内容，可以从全文逐层折叠为主题地图。用 Shift＋滚轮、滑杆或数字键 1–5 切换层级。

## A 阅读由你决定
全文保留所有细节。简述留下每段前两句。关键句层级只展示每段第一句。

要点层级保留每节第一句。主题层级显示各节标题。点击某一节，可以只展开感兴趣的内容。

## B 原句始终在场
折叠只改变原句的显示范围。它不改写内容，也不额外调用模型生成摘要。所有文字都保存在同一个 HTML 文件中。

把要点写在每段开头，折叠才有用。把原因放在第二句，再补充例子。必要的限制应与结论写在同一句中。

## C 图表也能阅读
全文和简述层级保留完整图表。更简短的层级隐藏图表，只展示段落中的说明。展开这一节即可查看流程。

```flow LR
Markdown草稿 -> HTML页面: 渲染
HTML页面 -> 全文: 默认打开
全文 -> 主题地图: Shift＋滚轮
主题地图 -> 全文: 展开
```

## D 离线也可使用
这份示例可以保存后离线打开。阅读层级和动画都在浏览器内运行。打印时会显示完整内容。

默认从全文开始阅读。你也可以在草稿中设置其他起始层级。降低动态效果的系统设置会关闭文字动画。
